# Syntax highlighting

Each file is highlighted according to its language, detected from its name: its extension, or its
whole name for files like `Makefile`. A file whose language is unknown is displayed as plain text.

## Themes

The dark theme is `Monokai Extended`, the light one is `GitHub`. Only their **foreground** colors
are used, so that the backgrounds of the diff stay visible:

- removed lines are red
- added lines are green
- `code` keeps its colors on both
