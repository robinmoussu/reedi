# What we decided about the names of the files that do not fit on a single row

- the name stays at the top of the screen until the last row of the file is scrolled away
- the last row of the file is never hidden by the name
- the name is shortened instead of being pushed away
- with a scrolloff smaller than 2, the name is pushed away once it is shortened to a single row
- clicking on the name never starts dragging the separator
- the mouse wheel scrolls as usual
- the line of the cursor stays highlighted, even below the name
